# @maradocs/shared

Shared Zod schemas, TypeScript types, constants, and slug rules used by the
MaraDocs server, CLI, and dashboard.

This package is an internal building block of [MaraDocs](https://github.com/bnap00/maradocs#readme);
install `@maradocs/cli` or `@maradocs/server` instead unless you are
building on the MaraDocs API types directly.
