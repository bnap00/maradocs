# Security Policy

## Supported Versions

Only the latest release of MaraDocs receives security fixes.

## Reporting a Vulnerability

**Please do not report security vulnerabilities through public GitHub issues.**

To report a vulnerability, email **bnap00@gmail.com** with:

- A description of the vulnerability
- Steps to reproduce
- The potential impact
- Any suggested fixes (optional)

You will receive a response within 72 hours. If the issue is confirmed, we will:

1. Work with you on a fix
2. Coordinate a disclosure timeline (typically 90 days)
3. Credit you in the release notes (unless you prefer to remain anonymous)
